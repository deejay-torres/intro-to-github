Intro-to-GitHub
Description

This repository was created as part of Assignment #3: Introduction to GitHub for IV-CCSAD. It demonstrates the basic use of Git and GitHub for version control, including creating a repository, uploading files, and managing changes through cloning, committing, and pushing.

Purpose

The purpose of this repository is to practice fundamental GitHub skills such as:

Creating and organizing a repository
Uploading and managing project files
Using Git locally to track, commit, and push changes
Understanding basic version control concepts (commits, branches, and merging)
